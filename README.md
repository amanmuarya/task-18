# Interactive Web Page Assignment

## Objective
The objective of this assignment is to design a simple web page with interactive elements using HTML, CSS, and JavaScript.

## Features
**Dynamic Greeting:** The header starts with "Hello". Users can enter their name into the input field, click the "Greet" button, and the header will update to say "Hello, Name  and last add + ji "
- **Interactive Color Boxes:** Four labeled boxes (Red, Blue, Green, Yellow) are displayed. Using JavaScript DOM manipulation, clicking on a box changes its background color to the respective color mentioned in the box.

## Files Included
- `index.html`: Contains the structural layout of the page (header, boxes container, input, and button).
- `style.css`: Contains the styling to make the layout visually appealing, replicating the sample output
`script.js: Contains the DOM logic for user interactions (button clicks and box clicks).
- `Readme.md`: Project documentation and instructions.

## Instructions / How to Run
1. Ensure all files (`index.html`, style.css, `script.js`) are located in the same directory/folder.
2. The CSS and JS files are already properly linked inside the `index.html` file.
3. Open `index.html` in any modern web browser (like Chrome, Firefox, or Edge) to test the page.
4. Test the functionality by typing a name and clicking "Greet", and by clicking each of the four colored boxes.
